I build applications that make everyday work easier: managing rental bills, organizing classrooms, and turning an inbox into clear next steps.

My work spans React and Next.js interfaces, TypeScript and Python backends, database design, and cloud automation. I care about the details between screens—how data moves, how a workflow handles mistakes, and whether the next step is clear to the person using it.

Based in **Pasay, Philippines**, I also work on internal systems, dashboards, and reporting automation with Python and Google Cloud.

## Selected work

### [Mailkind](https://github.com/Lopez-JhonLay/personal-inbox-traige-agent)
An AI inbox assistant that summarizes emails, surfaces requests and deadlines, and tracks follow-ups. Suggested replies stay under the user's review.

<sub>React · TypeScript · Python / Flask · PostgreSQL · OpenRouter</sub>

### [Rental Bill Management System](https://github.com/Lopez-JhonLay/rental-bill-management-system)
A workspace for rental units, tenants, utility readings, and monthly bills. Saved rate snapshots and a draft-to-confirm workflow keep billing records consistent.

<sub>React · TypeScript · NestJS · Prisma · PostgreSQL</sub>

### [Classroom Randomizer](https://github.com/Lopez-JhonLay/classroom-randomizer)
A classroom tool for managing student lists and randomly selecting students, with saved classroom data and an animated selection experience.

<sub>Next.js · TypeScript · Prisma · PostgreSQL · Tailwind CSS</sub>
