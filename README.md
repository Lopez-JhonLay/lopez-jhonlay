## 👋 Hi there

I'm **Jhon Lay Lopez**, a **full-stack application developer** based in Pasay, Philippines. I build web applications, internal tools, and automated workflows with React, Next.js, TypeScript, and Python.

My projects range from rental billing and classroom tools to an AI inbox assistant. I like turning a practical problem into software that's clear to use and straightforward to maintain.

## 🚀 Expertise

I work across the application stack: building interfaces, designing REST APIs, modeling data, and connecting third-party services. My backend work includes NestJS and Flask, with PostgreSQL and Prisma for application data.

I also build dashboards and automate reporting with **Python and Google Cloud**, including BigQuery and Cloud Run Functions. **Playwright** is part of my toolkit for browser automation and testing.

I'm growing my **AI engineering** skills through projects like Mailkind—connecting models to existing services, structuring their output, and giving users a way to review the results before acting.
